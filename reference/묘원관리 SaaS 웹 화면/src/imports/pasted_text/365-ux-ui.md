# 묘원365 UX/UI 설계 요청

묘원365는 공원묘원 관리자가 사용하는 웹 기반 B2B 업무관리 시스템이다.

기존 데스크톱 프로그램인 "묘원지기"의 업무 기능을 참고하되, 기존 프로그램의 화면 구조를 그대로 복제하지 말고 웹 환경에 적합한 UX/UI로 재설계한다.

목표는 "기능을 많이 보여주는 프로그램"이 아니라,

**계약 생성 → 계약서 발송 및 서명(이****폼사인) -> 계약완료 or 반려 -> (반려시 계약서 수정후 재발송)**

**(기존 계약건) 안치자 추가 → 묘역 → 비용 → 납부 → 관리비 → 청구 → 미납 → 상담/민원 → 해약/이장**

이라는 묘원 운영 업무의 전체 Lifecycle을 하나의 일관된 UX로 연결하는 것이다.

---

# 1. UX 설계 원칙

다음 원칙을 반드시 따른다.

### 1) 계약 중심 UX

묘원365의 핵심 업무 단위는 "회원"보다 "계약"이다.

하나의 계약에서 다음 정보를 연결해서 확인할 수 있어야 한다.

* 계약자
* 신청인
* 안치자
* 묘역
* 계약정보
* 설묘정보
* 비용
* 납부
* 관리비
* 청구
* 미납
* 상담/민원
* 메모
* 이장
* 해약
* 관련 문서

사용자가 여러 메뉴를 이동하지 않아도 계약 상세 화면에서 관련 업무를 처리할 수 있도록 설계한다.

---

### 2) 업무 중심 UX

관리자가 실제로 해야 하는 행동을 기준으로 화면을 구성한다.

예:

* 신규 계약 등록
* 묘역 배정
* 안치자 등록
* 비용 등록
* 납부 처리
* 관리비 청구
* 미납 확인
* 상담 기록
* 해약 처리
* 이장 처리

단순히 데이터를 보여주는 화면보다 "다음에 무엇을 해야 하는지" 명확하게 보여준다.

---

### 3) 검색과 필터를 중요하게 설계

묘원 관리자는 회원번호, 계약자, 안치자, 묘역번호, 연락처, 등록일, 관리기간 등으로 기존 계약을 빠르게 찾아야 한다.

따라서 검색 UI를 매우 중요하게 설계한다.

예:

검색어:
[ 회원번호 / 계약자 / 안치자 / 묘역번호 / 연락처 ]

필터:

* 계약상태
* 관리상태
* 납부상태
* 묘역상태
* 등록일
* 관리종료일

---

### 4) 상태(Status)를 명확하게 표현

업무 시스템에서 상태를 직관적으로 파악할 수 있도록 한다.

예:

계약상태

* 상담
* 예약
* 계약
* 해약

납부상태

* 납부완료
* 부분납부
* 미납
* 장기미납

묘역상태

* 판매가능
* 예약
* 계약
* 설묘
* 안치
* 이장
* 사용불가

관리자는 목록을 보는 것만으로 중요한 상태를 빠르게 파악할 수 있어야 한다.

# 3. 핵심 시퀀스

UI를 만들기 전에 아래 핵심 업무 시퀀스를 기준으로 화면을 설계한다.

## 핵심 시퀀스 1 — 신규 계약

대시보드
→ 계약관리
→ 신규 계약

→ 묘역 선택

---

# 5. UX/UI 디자인 방향

## Desktop First

주 사용자는 공원묘원 직원이며 PC에서 업무를 수행한다.

따라서 Desktop First로 설계한다.

권장:

* 좌측 Sidebar Navigation
* 상단 Global Search
* Breadcrumb
* Page Header
* Filter/Search Area
* Data Table
* Detail Drawer 또는 Detail Page
* Modal은 단순 확인/입력 작업에 제한적으로 사용

---

## 디자인 스타일

"관공서/구형 ERP"처럼 보이지 않으면서도 지나치게 화려한 SaaS 스타일도 피한다.

방향:

* 전문적인 B2B SaaS
* 높은 정보 밀도
* 명확한 계층 구조
* 빠른 검색과 업무 처리
* 상태 중심 UI
* 충분한 여백
* 읽기 쉬운 Typography
* 일관된 버튼 체계
* 명확한 성공/경고/위험 상태

  🎨 추천 컬러 배합 (Color Palette)

  B2B SaaS 특유의 신뢰감과 깔끔한 가독성을 유지하도록 구성한 **3가지 가이드**입니다.

  #### Option 1. Deep Forest & Sage (가장 추천: 중후함 + 현대적 감각)

  기존 남색이 주던 무게감을 유지하면서도 고급스러운 자연의 느낌을 주는 배합입니다.

  * **Primary (메인 포인트)**: `#1E3A2B` (Forest Green - 깊고 중후한 포레스트 그린)
  * **Secondary (보조/강조)**: `#3B7A57` (Sage Accent - 밝고 선명한 세이지 그린)
  * **Background (배경)**: `#F8FAFC` 또는 `#F3F6F4` (은은한 웜 그레이/세이지 틴트)
  * **Status Badges (상태 컬러)**:

    * **완납 / 정상**: `#10B981` (Emerald)
    * **미납 / 경고**: `#EF4444` (Crimson)
    * **진행 중 / 대기**: `#F59E0B` (Amber)

  #### Option 2. Emerald & Slate Gray (청량함 + B2B 세련미)

  최신 B2B SaaS 대시보드 스타일에 맞춘 선명하고 트렌디한 배합입니다.

  * **Primary (메인 포인트)**: `#0F5132` (Deep Emerald - 명확하고 신뢰감을 주는 초록)
  * **Secondary (보조/강조)**: `#198754` (Bright Emerald - 버튼 및 액션 아이템)
  * **Neutral Dark (텍스트/사이드바)**: `#1E293B` (Slate - 어두운 슬레이트 패널)
  * **Background (배경)**: `#F8FAFC` (클린 화이트/슬레이트)

  ### 💡 피그마(Figma) UI 적용 팁

  1. **사이드바(LNB) 및 헤더**: 메인 Primary 컬러(`#1E3A2B` 또는 `#0F5132`)를 LNB 배경이나 브랜드 포인트로 활용하면 화면의 중심을 안정감 있게 잡아줍니다.
  2. **이폼사인 / 수납 상태 태그**: 초록색이 메인 브랜드 컬러가 되므로, '완납(PAID)' 상태 태그는 메인 컬러보다 한 단계 밝은 채도의 초록(`#10B981`)을 사용하여 시각적 구분을 명확히 해주는 것이 좋습니다.
